PROJECT DESCRIPTION:
Weather Checker Application - A web application that provides real-time weather 
updates and 7-day forecasts for any location worldwide using external API data.

API INFORMATION:
- API Name: WeatherAPI.com
- Documentation: https://www.weatherapi.com/docs/
- Endpoints Used:
  * Current Weather: https://api.weatherapi.com/v1/current.json
  * Weather Forecast: https://api.weatherapi.com/v1/forecast.json
- API Key: Already configured in weather.js file

FEATURES:
- Real-time weather data for any location
- 7-day weather forecast with day/night temperatures
- Major cities' weather display (Cagayan de Oro, Davao, Zamboanga, General Santos)
- Responsive design for all devices
- Dynamic weather condition styling with gradients
- Error handling for invalid locations
- Modern UI with smooth animations

FILES INCLUDED:
- index.html (Standalone Group Portfolio Homepage)
- app.html (Standalone Weather Application)
- style.css (Styles for both pages)

- drizzle.png (App icon)
- dp.png, sisora.jpg, cabanete.png, monoy.jpg (Team member photos)

HOW TO RUN THE APPS:
PORTFOLIO (index.html):
1. Open index.html in any modern web browser
2. Browse through the team portfolio, project information, and team members
3. Click "Open Weather App" button to access the weather application

WEATHER APP (app.html):
1. Open app.html directly in any modern web browser
2. Enter any city name in the search field and click SEARCH
3. View current weather and 7-day forecast
4. Click "← Portfolio" to return to the team portfolio

SPECIAL INSTRUCTIONS:

- API key is already configured and functional
- Works on all modern browsers (Chrome, Firefox, Safari, Edge)
- Fully responsive design works on desktop, tablet, and mobile devices
- No additional setup or installation required
